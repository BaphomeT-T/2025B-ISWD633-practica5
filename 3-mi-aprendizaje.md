El principal aprendizaje logrado fue la capacidad de orquestar aplicaciones complejas usando Docker Compose, definiendo múltiples servicios (SonarQube y PostgreSQL), sus volúmenes de datos, una red compartida, y configurando dependencias avanzadas con healthchecks (service_healthy) para asegurar que los servicios críticos (como la base de datos) estén listos antes de iniciar el servicio principal, una habilidad fundamental para el desarrollo y despliegue profesional de microservicios.
